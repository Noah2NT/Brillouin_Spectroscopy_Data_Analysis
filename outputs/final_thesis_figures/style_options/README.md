# Figure style options

These four options share identical schematic content, force curves and labels. Only visual styling changes.

- A: Clean journal. Arial | restrained colour | flat vector shapes.
- B: Classic academic. Times New Roman | monochrome | fine outlines.
- C: Soft biological. Calibri | teal and violet | softer cell illustration.
- D: Technical schematic. Consolas | strong geometry | unfilled line drawing.

Option A was selected and locked in by Noah as the report-wide style. A PNG preview and editable SVG are supplied for each option. Figure-specific content review continues separately.
