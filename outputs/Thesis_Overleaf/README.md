- `BrillouinMicroscopy.bib`: the 17 cited works, including the previously missing entries and verified additions.
- `figures/`: 15 revised figures, each supplied as vector PDF, 300 dpi PNG and editable SVG. The source includes the PDFs.
- `REVISION_NOTES.md`: changes made, conditional feedback and remaining calibration work.
